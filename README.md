## 🌐 繁體中文 (Traditional Chinese)

### 📌 項目簡介
专为柬埔寨求职招聘打造的跨平台移动端应用，基于 React + Capacitor + PWA 构建，具备极致的流畅度与离线工作能力。

### ✨ 核心特色 (Key Features)
1. **极致流畅体验**：基于 React + Tailwind CSS 打造的现代化深色与亮色自适应界面，原生级别的滑动交互。
2. **Capacitor 跨端打包**：一套代码同时生成 Android APK、iOS App 和 PWA 网页版。
3. **本地离线支持**：支持简历缓存、离线职位浏览及断网自动重连同步。
4. **即时通讯**：集成实时在线聊天功能，求职者可与招聘方直接进行文字、语音及附件沟通。

### 📊 關鍵指標：市場需求度與商業前景
#### 📈 市場需求度 (Market Demand)
柬埔寨移动互联网普及率极高，绝大多数用户完全依赖智能手机获取信息。高棉职通车移动端通过提供极致的加载速度和离线模式，解决了本地网络不稳定的痛点，极大降低了求职门槛，市场刚需属性极强。

#### 🚀 發展前景 (Future Outlook)
1. **本地多语言全面支持**：深度优化高棉语、中文、英文三语即时翻译，消除跨国招聘的语言障碍。
2. **短视频求职**：引入类似 TikTok 的短视频简历功能，让求职者通过 30 秒自我介绍视频展现风采。
3. **智能地图求职**：基于 LBS 地理位置，提供「附近的工作」一键导航求职功能。

## 🇬🇧 English

### 📌 Project Overview
A highly responsive cross-platform mobile application designed for Cambodia's job market, built using React, Capacitor, and Progressive Web App (PWA) standards.

### ✨ Key Features
1. **Fluid UI/UX**: Built with React and Tailwind CSS, featuring adaptive dark/light modes and native-like gesture controls.
2. **Cross-Platform Delivery**: Single codebase compiled into native Android APK, iOS App, and web-ready PWA via Capacitor.
3. **Offline Capability**: Features local resume caching, offline job browsing, and automatic synchronization upon reconnection.
4. **Instant Messaging**: Embedded real-time chat allowing direct text, voice, and file exchange between candidates and recruiters.

### 📊 Market Demand & Commercial Outlook
#### 📈 Market Demand
Cambodia boasts an exceptionally high mobile internet penetration rate, with most users relying solely on smartphones. By offering lightning-fast loading speeds and offline capabilities, KhmerCareer Mobile App directly resolves the local challenge of unstable connectivity, resulting in a highly sticky user base.

#### 🚀 Future Outlook
1. **Tri-Lingual Real-time Translation**: Deeply optimize Khmer, Chinese, and English translation to break communication barriers in multinational firms.
2. **Short-Video Resumes**: Introduce a TikTok-like video resume feed, enabling candidates to pitch themselves in 30 seconds.
3. **LBS Job Discovery**: Implement location-based services (LBS) to allow users to discover and navigate to nearby job opportunities on a map.

### 🏗️ Tech Stack
`React, Capacitor, TypeScript, Tailwind CSS, Progressive Web App (PWA), LocalForage`
